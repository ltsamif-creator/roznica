# Loyalty Program - Веб-сайт программы лояльности

## Описание проекта
Веб-сайт для регистрации покупателей в программе лояльности, предоставления личного кабинета с кодом скидки и экспорта данных в 1С ERP.

## Структура проекта

```
loyalty-program/
├── app/
│   ├── static/
│   │   ├── css/          # Стили
│   │   ├── js/           # JavaScript
│   │   └── images/       # Изображения
│   ├── templates/
│   │   ├── public/       # Публичные страницы (регистрация, вход)
│   │   ├── dashboard/    # Личный кабинет покупателя
│   │   ├── admin/        # Административная панель
│   │   └── includes/     # Переиспользуемые компоненты
│   ├── models/           # Модели базы данных
│   ├── routes/           # Маршруты приложения
│   ├── services/         # Бизнес-логика (SMS, экспорт)
│   └── utils/            # Утилиты (генераторы, валидаторы)
├── config/               # Конфигурация
├── migrations/           # Миграции БД
├── tests/                # Тесты
├── data/                 # Данные (экспорт CSV/XLSX)
├── requirements.txt      # Зависимости Python
├── .env.example          # Пример переменных окружения
└── README.md             # Документация
```

## Технологический стек

- **Backend**: Python 3.9+, Flask
- **Database**: SQLite (для разработки), PostgreSQL (для продакшена)
- **ORM**: SQLAlchemy
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **SMS Gateway**: Интеграция через API (настраиваемая)
- **Export**: pandas (XLSX), csv (CSV)

## Установка и запуск

1. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения:
```bash
cp .env.example .env
# Отредактируйте .env под вашу среду
```

4. Инициализируйте базу данных:
```bash
python app/init_db.py
```

5. Запустите приложение:
```bash
python run.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Основные функции

### Публичная часть
- Регистрация по QR-коду с параметром магазина
- Подтверждение телефона через SMS
- Вход по телефону + SMS-код (passwordless)

### Личный кабинет
- Отображение уникального 10-значного кода скидки
- История операций
- Отзыв согласия на обработку ПДн

### Административная панель
- Управление пользователями
- Экспорт данных в XLSX/CSV
- Статистика регистраций
- Настройки программы лояльности

### Интеграция
- Экспорт данных для загрузки в 1С ERP
- Формат совместимый со Frontol 6

## Требования к коду скидки

- 10-значное число (например: 0010001234)
- Первые 3 разряда - код магазина (001-013)
- Оставшиеся 7 - порядковый номер
- Гарантированная уникальность
- Непредсказуемая генерация

## Безопасность

- Хеширование паролей администраторов (bcrypt)
- Rate limiting для предотвращения спама
- Защита от CSRF-атак
- Соответствие 152-ФЗ (персональные данные)
