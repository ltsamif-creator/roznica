### Компоненты Интерфейса

#### 1. Цветовая Палитра
**Primary (Синий)** - Основной цвет бренда
- `--primary-500: #1a5276` - основной
- `--primary-600: #154360` - hover состояние
- `--primary-700: #10354a` - активное состояние

**Secondary (Голубой)** - Вторичный цвет
- `--secondary-600: #2e86c1`

**Accent (Оранжевый)** - Акцентный цвет
- `--accent-500: #e67e22`

**Success (Зеленый)** - Успешные действия
- `--success-500: #27ae60`

**Danger (Красный)** - Ошибки и предупреждения
- `--danger-500: #e74c3c`

**Warning (Желтый)** - Предупреждения
- `--warning-500: #f39c12`

**Gray Scale** - Нейтральные цвета
- От `--gray-50: #f8f9fa` до `--gray-900: #212529`

#### 2. Типографика
- **Шрифт**: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
- **Line-height**: 1.6
- **Размеры заголовков**:
  - Landing title: 36px (mobile: 20px)
  - Auth title: 24px
  - Section headers: 20px

#### 3. Компоненты

##### Кнопки
- `.btn` - базовый класс
- `.btn-primary` - основная кнопка с градиентом
- `.btn-outline` - контурная кнопка
- `.btn-success` - успешное действие
- `.btn-secondary` - вторичное действие
- `.btn-lg` - большая (14px padding)
- `.btn-sm` - маленькая (6px padding)
- `.btn-block` - на всю ширину

##### Формы
- `.form-group` - группа полей
- `.form-control` - поле ввода
- `.checkbox-label` - чекбокс с лейблом
- `.form-text` - подсказка под полем

##### Карточки
- `.card` - базовая карточка
- `.card-header` - заголовок карточки
- `.card-body` - содержимое карточки
- `.bg-primary`, `.bg-success`, `.bg-info` - цветные варианты

##### Alert Сообщения
- `.alert-success` - успех (зеленый)
- `.alert-error` / `.alert-danger` - ошибка (красный)
- `.alert-warning` - предупреждение (желтый)
- `.alert-info` - информация (голубой)

##### Grid System
- `.container` - фиксированная ширина (max 1200px)
- `.container-fluid` - полная ширина
- `.row` - строка flexbox
- `.col-md-3`, `.col-md-6`, `.col-md-12` - колонки

#### 4. Тени (Shadows)
- `--shadow-sm`: 0 1px 3px rgba(0,0,0,0.05)
- `--shadow-md`: 0 4px 6px rgba(0,0,0,0.07)
- `--shadow-lg`: 0 10px 20px rgba(0,0,0,0.1)
- `--shadow-xl`: 0 20px 40px rgba(0,0,0,0.15)

#### 5. Border Radius
- `--radius-sm`: 4px
- `--radius-md`: 8px
- `--radius-lg`: 12px
- `--radius-xl`: 16px
- `--radius-full`: 9999px (круглый)

#### 6. Transitions
- `--transition-fast`: 0.15s ease
- `--transition-base`: 0.3s ease
- `--transition-slow`: 0.5s ease

## 4. Рекомендации по Использованию

### Для Разработчиков

1. **Используйте новые дизайн-токены:**
   ```css
   /* Вместо жестко заданных значений */
   background: var(--primary-500);
   border-radius: var(--radius-lg);
   box-shadow: var(--shadow-md);
   transition: all var(--transition-base);
   ```

2. **Градиентные кнопки:**
   ```html
   <button class="btn btn-primary">Основная</button>
   <button class="btn btn-success">Успех</button>
   <button class="btn btn-secondary">Вторичная</button>
   ```

3. **Карточки для дашборда:**
   ```html
   <div class="card bg-primary text-white">
     <div class="card-body">
       <h5 class="card-title">Заголовок</h5>
       <p class="card-text display-4">123</p>
     </div>
   </div>
   ```

4. **Grid система:**
   ```html
   <div class="row">
     <div class="col-md-3">25% ширина</div>
     <div class="col-md-6">50% ширина</div>
     <div class="col-md-12">100% ширина</div>
   </div>
   ```

### Для Дизайнеров

1. **Цветовая схема готова к расширению** - все оттенки документированы
2. **Компоненты модульные** - легко комбинировать
3. **Responsive дизайн** - mobile-first подход в media queries
4. **Доступность** - достаточный контраст цветов
